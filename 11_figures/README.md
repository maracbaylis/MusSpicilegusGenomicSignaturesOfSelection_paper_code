# 11 — Figure-generation scripts

## Purpose

Collect scripts used to build manuscript and supplementary figures from the
analysis outputs generated by the preceding repository sections.

These scripts do not define the core statistical tests. Their inputs are
tables produced by the PAML, phyloP, expression/Brownian-motion, GO, Enformer,
and brain-region analyses.

## Figure groups

### Comparative-genomic discovery/QC figures

These scripts visualize lineage- and developmental-stage patterns from phyloP
and alignment-QC outputs:

```text
plot_all_species_mixed_strict_qc.py
plot_all_species_spic_indel_aware_qc.py
plot_left_cerebral_and_frontal_cortex_discovery_rate.py
plot_standardized_species_count_barplots.py
```

For example, the cortical discovery-rate script combines left cerebral cortex
and frontal cortex summaries and plots species-specific discovery rates across
developmental timepoints.

### Brownian-expression figures

```text
build_behavior_candidate_bm_z_dotplots.py
plot_selected_polytomy_BM_profiles.py
```

These scripts consume the species-mean expression and Brownian residual tables
generated by `05_expression_preprocessing/` and `06_brownian_expression/`.

### Brain-region / Allen Atlas figures

```text
plot_phylop_frontal_prefrontal_main_figure.py
plot_phylop_puberty_plus_frontal_heatmap.py
```

These scripts visualize Allen Mouse Brain Atlas expression-energy matrices for
genes linked to accelerated cCREs.

### Developmental cCRE figures

```text
plot_gene_annotated_proportion_publication.py
recreate_transient_enhancers_publication.py
```

These scripts visualize developmental enhancer presence/gene annotation across
timepoints from `enhancer_presence_matrix.xlsx`.

### Conceptual/model figures

```text
make_memory_plasticity_schematic.py
make_spicilegus_spine_pruning_model_figure.py
```

These are manuscript schematics/model figures assembled from selected genes
and previously computed results. They should be interpreted as visualization
and synthesis code rather than independent statistical analyses.

## Inputs

Most scripts expect result tables produced elsewhere in the repository and use
`MSPIC_PROJECT_ROOT` and/or `MSPIC_INPUT_DIR` to resolve those paths.

Several scripts still contain historical relative paths to analysis outputs.
For a public repository, either:

1. retain the repository directory structure expected by the scripts; or
2. convert those paths to command-line arguments/environment variables before
   release.

Do not duplicate large intermediate result tables in this folder if they are
already generated by upstream analysis sections.

## Requirements

Depending on the figure:

- Python >= 3.10
- pandas
- numpy
- matplotlib
- seaborn
- pillow

No figure script should be required to reproduce the statistical conclusions;
the corresponding analysis code lives in earlier repository sections.
